# TechRAMEN 2026 セッションタイマー

技術イベントのセッション発表で残り時間を分かりやすく伝えるための、タブレット向け PWA セッションタイマーです。  
[TechRAMEN 2026 Conference](https://techramenconf.net/2026/) の「手作り × 富良野ワイン」のトーン＆マナーをベースに、Vue.js と [Vite+](https://viteplus.dev/) で構築しています。

## 主な機能

- **残り時間に応じたフルスクリーン背景色の変化**
  - **待機中**: クラフト紙（`#f3e8d8`）
  - **進行中**: 富良野の畑・緑（`#3e5e22`）
  - **残りわずか（予告）**: 富良野の黄金色（`#d99b26`）
  - **まもなく終了**: 富良野ワイン（`#8d1f32`）
  - **時間超過**: 深紅ワイン＋警告リング（`#3b0d17` / `+MM:SS` カウントアップ）
- **TechRAMEN 2026 向けプリセット**
  - `［立ち食い］LT (5分)` / `［一杯］トーク (20分)` / `［餃子セット］トーク (40分)` / `［麺打ち］ハンズオン (40分)` / `15分` / `60分` / 自由入力
- **タブレット・ステージ運用向け設計**
  - **PWA 対応**: `manifest.webmanifest` と Service Worker によるビルド成果物プリキャッシュで、ホーム画面へのインストールとオフライン動作に対応
  - **Wake Lock API**: カウントダウン実行中の画面自動スリープを抑制
  - **誤操作防止ロック**: 鍵ボタンでロックし、長押し（0.8秒）で解除
  - **進行中調整**: `-1分` / `+1分` ボタンで押した・巻いた場合も即座に補正
  - **URL クエリ指定**: `?m=20&title=2F+大ホール` や `?preset=lt-5` で会場タブレット向けブックマークが可能

## 開発コマンド（Vite+）

```sh
# 依存関係のインストール
pnpm install

# 開発サーバー起動 (vp dev)
pnpm dev

# フォーマット・Lint・型チェック (vp check)
pnpm check

# テスト実行 (vp test)
pnpm test:unit

# 本番ビルド (vue-tsc + vp build)
pnpm build

# ビルド結果のローカルプレビュー (vp preview)
pnpm preview
```

## タブレットへの PWA インストール方法

- **iPad / iPhone (Safari)**: 公開 URL を開き、共有ボタン（□↑）→「ホーム画面に追加」をタップします。
- **Android (Chrome)**: 設定シート内の「アプリをインストール」ボタン、またはブラウザメニューの「アプリをインストール」を選択します。

## GitHub Pages デプロイ

`.github/workflows/deploy.yml` に GitHub Actions ワークフローを用意しています。  
リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定し、`main` ブランチへ push すると自動でチェック・テスト・ビルド・公開が行われます。
